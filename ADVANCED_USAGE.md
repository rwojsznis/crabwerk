# Crabwerk first mode

Crabwerk first mode can be used if your entire team is using `crabwerk`. Currently, the only thing this does is change the copy in `package_todo.yml` files to reference `crabwerk` instead of `packwerk`.

There are two ways to enable this:
1. Rename `packwerk.yml` to `crabwerk.yml` and crabwerk first mode will be automatically enabled.
2. Set `crabwerk_first_mode: true` in your `packwerk.yml`
